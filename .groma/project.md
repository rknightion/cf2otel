cf2otel polls the Cloudflare REST and GraphQL APIs and exports what Cloudflare otherwise reserves for Enterprise Logpush as OTLP logs, metrics and traces, built for Grafana Cloud. AGENTS.md "Ownership seams" is the source of truth for package boundaries.
