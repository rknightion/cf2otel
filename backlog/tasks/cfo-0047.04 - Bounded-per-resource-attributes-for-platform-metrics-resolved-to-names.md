## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
D1, KV, Queues and Durable Objects metrics drop the database, namespace and queue identifiers on purpose to bound cardinality, which makes it impossible to see which resource is busy. R2 operations also lack the action type. Resource IDs should resolve to names via the read-only list endpoints and be capped.
<!-- SECTION:DESCRIPTION:END -->
