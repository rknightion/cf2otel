## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Status class alone hides 403 vs 404 vs 502, origin errors are invisible behind edge status, and there is no country breakdown for geomaps. These are bounded dimensions and are on by default per the cardinality policy.
