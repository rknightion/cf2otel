## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Which devices are connected, from where, and on which client version is the WARP fleet view. The fleet-status device endpoint returns one row per device; per-device series (device ID, name, email) are unbounded, so export aggregates and paginate fully (a single page silently truncates large fleets).
