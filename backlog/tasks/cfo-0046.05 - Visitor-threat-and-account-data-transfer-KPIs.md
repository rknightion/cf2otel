## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Zone overviews usually show visits, page views, threats and uniques, and a month-to-date data transfer figure with a linear end-of-month projection is a cheap single account-level query that supports billing alerts. The 1-minute rollup groups that carry some of these are plan-gated, so prefer adaptive equivalents and record per-plan availability.
