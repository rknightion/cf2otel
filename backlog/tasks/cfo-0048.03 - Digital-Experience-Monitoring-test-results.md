## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Root official DEX docs and current successful empty overview canary are recorded in doc-0003. Add disabled-by-default dex.tests snapshot collector, five-minute poll, bounded current one-hour result window (configurable one hour to seven days), complete page/per_page fifty test enumeration with a documented maximum test count. Fetch each test independently via the existing shared retrying client. Publish only complete valid results per test, atomically replace the metric-family snapshots for the successful subset, and return a safe joined collection error for failed tests so successful data is not suppressed. All failed requests preserve original expiry without refresh; genuine empty catalog clears snapshots. No window checkpoint, persistent ledger or new shared interface. Gauges use documented per-test average fetch/RTT/hops/percentage fields; units and bounded test labels frozen in the root brief before code. Missing optional values are omitted, not zero. API drift and permissions documentation in own scope; dashboard later; no populated-row/live-runtime claim.
<!-- SECTION:PLAN:END -->
