## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Workers CPU time and duration percentiles and the per-script error rate are the core Workers SLO signals, and cf2otel has none of them. workersInvocationsAdaptive exposes status, sums and quantiles. CFO-0023 skipped this dataset only as raw events (native Workers OTLP already sends invocation logs and traces); aggregate metrics from it are not covered by that export.
