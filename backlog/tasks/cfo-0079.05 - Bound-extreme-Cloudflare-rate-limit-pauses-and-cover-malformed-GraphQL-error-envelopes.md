## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
CFO-0079.04 (per-class Cloudflare rate limits driven by response headers) honours retry-after, Ratelimit and GraphQL budget errors with no upper bound on a valid but extreme pause, so one upstream header could stall a whole request class for hours. Its tests also cover only well-formed GraphQL error envelopes; mixed or malformed envelopes (errors alongside data, missing extensions, non-string codes) were not exercised. Raised as an open question at the loop22 closeout; owner admitted it for loop23 ahead of the attribution measurement.
